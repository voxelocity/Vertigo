# Vertigo

A two-lane rhythm game for the browser. Left and right, on the beat.

**Play it:** _(demo link goes here)_

![screenshot](docs/screenshot.png)

## How to play

| Key | Lane  |
| --- | ----- |
| ←   | Left  |
| →   | Right |

Hit the note as it crosses the line. Closer is better.

## Running locally

```
npm install
npm run dev
```
